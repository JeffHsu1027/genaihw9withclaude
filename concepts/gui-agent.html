GUI 代理人（GUI Agent）

別名
GUI agent、圖形介面代理人、computer-use agent
最後更新
2026-11-16
來源數量
1 個來源

一句話定義

透過觀看畫面並用滑鼠與鍵盤操作圖形介面的 AI 代理人，使用軟體的方式和人一樣。

說明

多數程式之間的自動化靠的是 API 或程式碼。GUI 代理人走另一條路：它看到的是螢幕畫面，做出的動作是點擊、按鍵與捲動。這類代理人通常建立在能同時處理圖像與文字的模型上。

它的運作可以拆成反覆進行的三步：觀察目前的畫面，推理下一步該做什麼，執行一個輸入動作，然後再觀察畫面的變化。

這種做法的好處是通用：只要軟體有人類可用的介面，代理人就能操作，不需要軟體另外提供接口。代價是比直接呼叫程式慢，也可能看錯畫面或點錯位置。

各來源怎麼說

GUI Agents for Continual Game Generation（2026）

這篇論文主張，在各種可能替代人類測試員的方案中，只有 GUI 代理人是在與人類相同的視覺與輸入介面上接觸遊戲，因此是最自然的替身（p.3）。

論文先驗證它是否真的能玩遊戲。在約 120 個關卡上，三個模型 20 次嘗試內的通過率為 0.72 到 0.82，人類為 0.92（p.3）。作者指出代理人展現了測試員需要的三種能力：觀察畫面、推理下一步、執行動作（p.3）。

論文讓 GUI 代理人擔任兩個彼此獨立的角色：

  • 評審：拿著評分準則去玩遊戲，判定每條準則是否通過（p.4）。
  • 測試員：不看準則也不看程式碼，只回報遊玩經過與修正建議（p.5）。

不同模型擔任測試員時關注的重點差異很大，例如 Kimi K2.5 將近一半的回饋關於視覺與美感（p.7–8）。
