代理人記憶（Agent Memory）

別名
agent memory、記憶系統、情節記憶、技能記憶、世界記憶
最後更新
2026-11-16
來源數量
1 個來源

一句話定義

讓 AI 代理人把過去的經驗保存下來，並在之後的步驟或任務中取用的機制。

說明

語言模型本身不會記得上一次任務發生的事。如果沒有記憶機制，代理人每次都從零開始，同樣的錯誤會反覆出現。

代理人記憶的做法是把經驗寫成文字存起來，例如做過什麼嘗試、哪些有效、歸納出什麼通則，需要時再讀回來放進模型的輸入。這種方式不需要重新訓練模型，新的經驗可以立刻使用，內容也可以直接檢視與修改。

設計記憶時常見的兩個考量是：經驗要保留多久（只在目前任務內，或跨任務長期保存），以及給誰看（單一代理人私有，或多個代理人共用）。

各來源怎麼說

GUI Agents for Continual Game Generation（2026）

這篇論文觀察到同類型的失敗會反覆出現，例如平台遊戲的跳躍弧線錯誤，卻常常每次都要重新發現（p.6）。它依生命週期與範圍兩個維度設計了三層記憶（p.6）：

記憶層 生命週期 範圍 內容
情節記憶（Episode Memory） 任務內 兩個代理人共用 各回合的摘要、修正與嘗試
技能記憶（Skill Memory） 跨任務 各代理人獨立 寫程式的常見模式、試玩的互動策略
世界記憶（World Memory） 跨任務 所有代理人共用 通用的遊戲規則、常見類型與設計原則

消融實驗（以 GPT-5.4 為骨幹）顯示每一層都有貢獻（p.18）：

設定 準則通過率
不用記憶 64.1
只有情節記憶 69.3
情節加技能 71.8
三層完整 72.3

情節記憶的貢獻最大。作者說明，沒有它時，寫程式的代理人常會重新加回先前已經試過並放棄的修正（p.18）。

作者也把所有遊戲共用同一套記憶結構列為限制（p.9）。

相關概念

  • GUI 代理人（GUI Agent）：使用這套記憶的角色之一。
  • 微調（Fine-Tuning）：另一種讓系統從資料進步的方式，差別在於微調會改變模型參數，記憶不會。
