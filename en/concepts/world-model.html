World Model

One-line definition

An agent's internal model of its environment, which predicts what will happen next given the current state and an action.

Explanation

Reinforcement learning has two broad routes. One builds no model of the environment and learns how to act directly from trial and error. The other first learns a model of the environment and then uses it for planning or training; this is called model-based reinforcement learning.

A world model belongs to the second route. It usually does two things: it compresses high-dimensional observations, such as frames, into a compact representation, and it predicts how that representation changes with actions.

With a world model, an agent can practise in "imagination" and does not have to interact with the real environment at every step. This is especially valuable when real interaction is slow, expensive, or risky.

The main risk is that no model is perfectly accurate. If what the agent learns inside the model actually relies on the model's errors, it will stop working in the real environment.

What each source says

World Models (2018)

The world model in this paper has two parts (p.2–3):

  • Vision V: a variational autoencoder compresses each frame into a latent vector z.
  • Memory M: an MDN-RNN predicts the probability distribution of the next z. It outputs a distribution, not a single value, in order to handle randomness in the environment.

The world model is trained without supervision and never sees the reward; it only compresses and predicts (p.5). The paper demonstrates two uses:

  • Providing features. z and M's hidden state h are given to a very small controller. In car racing, using only z gives 632 ± 251, and adding h gives 906 ± 21 (p.6).
  • Replacing the actual environment. In Doom, the controller is trained entirely inside a "dream" generated by the world model. After transfer it survives about 1100 steps in the actual environment, above the 750 steps required (p.7–8).

The paper also documents the risk in detail: the controller finds policies that exploit the model's flaws, for example making monsters in the dream never shoot fireballs (p.8). The authors' remedy is to have M output a distribution and to raise the sampling temperature τ, which makes the dream harder and more random. Temperature is a trade-off between realism and exploitability (p.9).

The limitations the authors point out include limited model capacity and simulating only step by step without hierarchical planning (p.12–13).

Related concepts

  • Variational Autoencoder: the part of the world model that compresses frames.
  • Evolution Strategies: the method used here to train the controller.
  • Out-of-Distribution Generalization: a world model is wrong in states its training data did not cover.
  • Game Rule Understanding: a world model implicitly learns how a game works from frames.
  • Note: the "Memory M" in this paper is the internal state of a neural network. It is not the same thing as Agent Memory, which stores experience as text.
  • Note: a world model imitates an existing game. This differs from Game Generation, which creates a new game from a description.
