Sources

One page per paper: research question, method, key results, and limitations.

Source

LLM Game Rule Understanding through Out-of-Distribution Fine-Tuning

Bateni, Pratt & Whitehead · 2025

The authors use a custom Solitaire game description language to generate questions of the form "is this move legal, and what is the next state?", and find that a small amount of fine-tuning improves GPT-4o-mini's rule understanding, even on Solitaire variants it was not trained on. When the rules differ too much, however, fine-tuning barely helps.

 Source

GUI Agents for Continual Game Generation

Huang et al. · 2026

The authors argue that game generation needs a "player", and let GUI agents actually play generated web games: they use one to build the PlaytestArena benchmark, and put another inside the generation loop as Play2Code, which reaches an average rubric pass rate of 66.8%, above 29.7% for single-pass generation and 52.2% for an agentic pipeline that does not play.

 Source

World Models

Ha & Schmidhuber · 2018

The authors split an agent into vision, memory, and controller parts. They first learn, without supervision, a world model that compresses frames and predicts the future, and then use it to train a very small controller. This agent solves a car racing task, and can even be trained entirely inside a "dream" generated by its world model, with the learned policy then transferred back to the real Doom environment.

 Source

World and Human Action Models towards gameplay ideation

Kanervisto et al. · 2025

The authors first interview 27 game creatives and conclude that generative AI needs three capabilities to support creative ideation: consistency, diversity, and persistency. They then train WHAM on about 7 years of human gameplay; it is a world model that turns both frames and controller actions into discrete tokens and predicts them one by one with a transformer. The three capabilities are evaluated with FVD, the Wasserstein distance, and human annotation respectively.

Concepts

One page per concept: what different papers say about the same idea.

Concept

Game Rule Understanding

3 sources

Whether a model correctly grasps a set of game rules and can use them to judge, predict, play, or even evaluate and modify the rules themselves.

 Concept

Out-of-Distribution Generalization

2 sources

A model's ability to keep performing well on data that differs in nature from its training data.

 Concept

Fine-Tuning

1 source

Taking an already pre-trained model and continuing to train it on task-specific data so that it performs better on that task.

 Concept

Game Description Language

1 source

A formal language for describing game rules precisely, so that a program can read the rules directly and simulate the game.

 Concept

GUI Agent

1 source

An AI agent that operates a graphical interface by looking at the screen and using the mouse and keyboard, the same way a person uses software.

 Concept

Playtesting

1 source

Finding a game's problems by actually playing it; what is checked is the experience of play, not the code.

 Concept

Game Generation

3 sources

Having AI automatically produce a game, or part of one such as code, rules, levels, or gameplay clips, from a prompt given by a person, such as a natural-language description or reference frames.

 Concept

Agent Memory

1 source

A mechanism that lets an AI agent keep its past experience and use it in later steps or tasks.

 Concept

Evaluation Benchmark

3 sources

A fixed set of tasks plus a scoring method, used to measure an ability or the quality of an output in a repeatable way.

 Concept

World Model

2 sources

A model of an environment that predicts what will happen next given the current state and an action; it can be used to train an agent (World Models) or to generate content directly (WHAM).

 Concept

Variational Autoencoder

1 source

A neural network that learns to compress an input into a small latent vector and to reconstruct an approximation of the original input from that vector.

 Concept

Evolution Strategies

1 source

A family of optimization methods that imitate evolution: repeatedly generate many candidate parameter sets, evaluate each one, and produce the next generation from the candidates that did well.

 Concept

Creativity Support

1 source

Using tools to help people produce and develop new ideas; the point is to assist the human creative process, not to finish the work in the person's place.

 Concept

Vector Quantization

1 source

Replacing a continuous vector with the closest entry in a finite codebook, so that data can be represented as a sequence of discrete indices.

 Concept

Autoregressive Transformer

1 source

A sequence model that predicts each next token from only the tokens before it, then appends the result to the sequence and keeps generating.

 Concept

Reinforcement Learning

2 sources

Having an agent interact with an environment and adjust its behavior according to the rewards it receives, so that it gradually learns how to collect the most cumulative reward.
